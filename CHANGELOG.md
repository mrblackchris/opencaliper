# Changelog

## 0.1.0 — Unreleased

- Portable workspace archives with embedded source/derived channels and restored plot settings.
- Signal math and calculus, zero-phase filtering and recording alignment.
- Annotations, event detection and interactive PSD spectrograms.
- PNG/SVG/PDF plot export with legends, units and cursor measurements.
- Structural undo/redo and memory-mapped NPY input with cached, bounded-memory fit scans.

- Desktop data viewer with a shared file/signal explorer and independent analysis tabs.
- Resizable plots, shared/separate Y axes, configurable colors and logarithmic scales.
- Differential cursors, FFT workspaces and descriptive statistics.
- Command-line and Python interfaces for supported formats and conversions.
- Documented MAT interchange format and synthetic example generator.
- Automated numerical, format and GUI regression tests.
- Windows and Linux launchers with automatic local environment setup.
- User, architecture and developer guides with a documentation index.
- Doxygen API reference, linked source listings and Graphviz architecture drawings.
- Documentation CI builds downloadable HTML references and checks generation warnings.
