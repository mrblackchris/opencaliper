# Security

OpenCaliper processes local measurement files. Do not open untrusted files on a sensitive system; parsers and numerical dependencies can contain defects, and large recordings may exhaust memory. Keep the application and its dependencies up to date.

For a suspected security vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, open an issue containing only a general request for a private reporting channel. Do not post exploit details, secrets, private recordings or sensitive logs publicly.

Include the affected OpenCaliper/Python versions, operating system, relevant dependency versions, impact and a minimal synthetic reproduction in the private report. OpenCaliper is currently an early release; fixes target the current development version. No response-time or long-term-support commitment is made.
