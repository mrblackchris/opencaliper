# OpenCaliper application logo

`opencaliper.png` is the original generated raster logo, with transparency outside
the navy tile. It is loaded by Qt for window/application icons and referenced by
the optional Linux desktop launcher. Do not remove it from wheel/source packages.

Created with the built-in image-generation tool for this project. No reference
images were used. Qt scales the source to the operating system's icon sizes.

Generation prompt:

> Use case: logo-brand. Create a single polished desktop application icon for OpenCaliper, an open-source scientific signal viewer. A distinctive bold open caliper silhouette subtly combined with an oscilloscope waveform, readable as a compact emblem at 24 to 48 pixels. Flat vector-like design with clean geometric edges, restrained cyan and warm amber accents inspired by signal plotting on a dark navy rounded-square tile. Strong contrast, generous simple shapes, centered composition, ample margin, no lettering, no tiny ticks, no gradients or shadows, no surrounding mockup. Transparent background outside the rounded-square tile. This is the final app/taskbar icon, square canvas, one icon only.
